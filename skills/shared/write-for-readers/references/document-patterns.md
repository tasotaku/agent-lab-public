# 文書の種類別構成

必要な種類の節だけを使う。構成は目的に合わせて調整し、見出し名を機械的に転記しない。

## 目次

- 判断・提案
- 説明・概要
- 報告
- 手順
- 参照・FAQ

## 判断・提案

目的: 読者が選択、承認、合意できるようにする。

基本順:

1. 何を決めてほしいか
2. 推奨する結論
3. 判断に必要な現状と根拠
4. 選択肢と、結果が変わる差
5. リスク・未確定事項
6. 次の行動

結論を変えない調査経緯、全データ、細かな例外は詳細へ移す。読後に、読者が選択肢と選定理由を説明できれば完成。

## 説明・概要

目的: 読者が対象の全体像、位置づけ、理由をつかめるようにする。

基本順:

1. 何の話か、なぜ今読むのか
2. 読者が既に知っているものとの関係
3. 全体の流れ
4. 流れを構成する要素
5. 具体例
6. どこまで分かり、何が未確定か

一つの流れを最後まで通す。途中で別の問いへ移らない。読後に、読者が自分の言葉で全体の流れを説明できれば完成。

## 報告

目的: 起きたことと影響を共有し、次の対応を決められるようにする。

基本順:

1. 結果
2. 影響
3. 重要な事実
4. 未解決の問題
5. 次の対応と担当

時系列は、原因や判断に必要な場合だけ本文に残す。読後に、読者が現在地と次の担当を言えれば完成。

## 手順

目的: 読者が一つの作業を完了できるようにする。

基本順:

1. 完了状態
2. 始める前に必要なもの
3. 番号付きの操作
4. 各段階の正常な結果
5. 起こりやすい失敗と戻し方

説明や背景は、その操作を正しく選ぶために必要な分だけ置く。読者が補足なしで完了できれば完成。

## 参照・FAQ

目的: 読者が必要な事実を後から早く見つけられるようにする。

基本順:

1. 対象範囲と想定読者
2. 読者が検索する言葉に合わせた見出し
3. 表、定義、条件、例外
4. 出典と更新日

網羅性と探しやすさを優先する。最初から最後まで読ませる物語にしない。読者が想定した問いの答えを短時間で見つけられれば完成。
